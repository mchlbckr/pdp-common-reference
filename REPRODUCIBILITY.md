# Reproducibility checklist

## Environment the results were produced in

| Component | Version |
|---|---|
| R | 4.5.3 (2026-03-11) |
| renv | 1.2.3 (79 locked packages, CRAN) |
| targets | 1.12.0 |
| Quarto | 1.8.24 |
| TeX | LuaHBTeX 1.21.0, TeX Live 2025 |
| Platform | macOS (Darwin, arm64) |

The complete package set is pinned in `renv.lock`. Model classes are fitted
with base R, `mgcv`, `rpart`, `nnet`, `randomForest`, and `gbm`; figures use
`ggplot2` and `patchwork`.

## 1. Restore the environment

```r
renv::restore()
```

This installs the locked package versions into a project-local library. The
library itself is not tracked in the repository.

A LaTeX installation with LuaLaTeX is required only for rendering the
manuscript, not for running the pipeline.

## 2. Obtain the data

No raw data is redistributed. Follow the download commands in
[`data/README.md`](data/README.md) and verify the SHA-256 checksums listed
there before proceeding. The pipeline expects the files at the paths given in
that file.

## 3. Run the pipeline

```r
targets::tar_make()
```

The pipeline is the single source of truth for every number and figure in the
manuscript. It is computationally heavy: the full matrix crosses six prediction
model classes, three correlations, three grid widths, and five calibrated
validity rules, and several studies use repeated splits or bootstrap
resampling. Expect a multi-hour run on a single machine. Individual studies can
be rebuilt selectively, for example:

```r
targets::tar_make(names = tidyselect::starts_with("s33"))
```

Inspect what is out of date before committing to a full rebuild:

```r
targets::tar_outdated()
```

## 4. Run the tests

```r
testthat::test_dir("tests/testthat")
```

229 tests cover the estimators, the validity rules, and the simulation
machinery and pass without any data download. A further six tests exercise the
real-data case studies (`s16` wine quality, `s17` bank marketing and online
shoppers) and fail with an explicit "data file not found" message until step 2
has been completed. That is expected on a fresh clone, because no raw data is
redistributed here.

## 5. Render the manuscript

```sh
quarto render paper
```

Rendering reads stored objects from `_targets/` via `tar_read()` and the figure
panels from `results/`. Because both are included in this repository, step 3 is
**not** a prerequisite for producing the PDFs:

* `paper/_output/pdp-common-reference-jmlr.pdf`
* `paper/_output/pdp-common-reference-jmlr-supplement.pdf`

Neither PDF is tracked in the repository; both are regenerated by this step.
The `.qmd` sources are tracked, because the reported numbers are computed
inline from the target objects rather than typed into the text. Re-rendering is
therefore also the way to check that a printed value matches the pipeline.

## Determinism

Every stochastic study sets an explicit seed inside its `simulations/` script,
and repeated-split analyses derive per-split seeds from a fixed base seed. The
confirmatory California Housing analysis uses base seed `20261101` over 30
splits. Results are therefore reproducible for a given package set; minor
numerical differences may still arise across platforms or BLAS
implementations.

## Scope of the included results

`results/` contains the figure panels cited in the manuscript and supplement,
the panels listed as archived extended results, and machine-readable `.rds`
objects for the studies whose full output does not fit in the PDF.
[`results/extended-results-index.md`](results/extended-results-index.md)
records which panels were removed from the compact supplement and why. That
omission is editorial and does not change the computational record.

Exploratory pilot analyses that are not part of the manuscript are not included
in this archive.
